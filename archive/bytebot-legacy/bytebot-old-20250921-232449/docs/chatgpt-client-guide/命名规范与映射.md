# 文档命名规范与映射

本规范用于统一“ChatGPT 客户端教学”目录内文档的命名与链接，避免链接断裂并便于长期维护。

- 文件扩展名：一律使用 `.md`（小写）。
- 语言与字符：可保留中文标题与全角标点；禁止同一目录混用大小写扩展名（如 .MD）。
- 链接规范：统一使用相对路径链接（例如 `./使用 GPT 操作发送和返回文件.md`）。
- 锚点规范：本合并手册内使用自定义 HTML 锚点 `<a id="..."></a>` 保证稳定跳转。
- 重命名策略：仅在不改变语义的前提下统一扩展名和大小写；原始中文名称保留。

## 变更映射（旧名 → 新名）

- GPT Action 身份验证.MD → GPT Action 身份验证.md
- GPT Actions 库.MD → GPT Actions 库.md
- 为 ChatGPT 和 API 集成构建 MCP 服务器.MD → 为 ChatGPT 和 API 集成构建 MCP 服务器.md
- 使用 GPT 操作进行数据检索.MD → 使用 GPT 操作进行数据检索.md

> 注：仅统一扩展名，未修改中文标题及标点。
