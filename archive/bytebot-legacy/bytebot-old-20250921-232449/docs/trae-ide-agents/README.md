# Trae IDE 智能体文件夹

本文件夹包含了多角色视觉设计智能体团队的完整配置和文档。

## 文件说明

### 核心配置文件
- `trae_agent_configs.yaml` - Trae IDE智能体配置文件，包含13个Agent的详细配置
- `visual_design_agent_squad_design.md` - 多角色视觉设计智能体团队设计方案
- `智能体.md` - 原始智能体需求文档

### 项目管理文件
- `initial_backlog_sprint_plan.md` - 初始Backlog和Sprint执行计划
- `品牌资源替换用户故事.md` - 品牌资源替换相关的用户故事

### 使用说明文件
- `trae ide.md` - Trae IDE使用说明和操作指南

## 智能体团队架构

### 管理层 (2个Agent)
- 项目经理Agent
- 产品经理Agent

### 策略层 (3个Agent)
- 品牌策略师Agent
- 用户研究员Agent
- 设计系统架构师Agent

### 生产层 (5个Agent)
- UI设计师Agent
- 图标设计师Agent
- 插画师Agent
- 动效设计师Agent
- 前端开发Agent

### 质保层 (3个Agent)
- 设计审查员Agent
- 可用性测试员Agent
- 品牌合规检查员Agent

## 使用方法

1. 在Trae IDE中导入 `trae_agent_configs.yaml` 配置文件
2. 根据 `visual_design_agent_squad_design.md` 中的设计方案创建智能体
3. 按照 `initial_backlog_sprint_plan.md` 执行项目计划
4. 参考 `trae ide.md` 了解具体操作步骤

## 注意事项

- 所有智能体配置都基于Trae IDE官方文档设计
- 建议按照设计方案的5个阶段逐步实施
- 确保为每个智能体配置适当的工具和权限
