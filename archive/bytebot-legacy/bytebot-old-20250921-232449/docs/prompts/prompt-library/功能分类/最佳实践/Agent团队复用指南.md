## 协作最佳实践

### 跨角色协作

#### 需求到设计阶段
- **需求分析师 + 解决方案架构师**：
  - 共同参考`业务分类/方案设计/`进行需求可行性分析
  - 使用`功能分类/模板库/`标准化需求和设计文档
  - 基于`技术分类/AI_ML/`评估智能体能力边界

#### 设计到开发阶段
- **解决方案架构师 + 研发工程师**：
  - 共享`技术分类/`下的配置文件和技术方案
  - 使用`功能分类/工具使用/`统一开发环境和工具
  - 参考`故障排除/`预防和解决技术问题

#### 开发到测试阶段
- **研发工程师 + 测试工程师**：
  - 共同使用`功能分类/模板库/测试模板/`设计测试用例
  - 基于`业务分类/质量管理/`建立质量标准
  - 使用`技术分类/DevOps/`配置测试环境

#### 测试到发布阶段
- **测试工程师 + 交付运营 + 发布经理**：
  - 共同参考`业务分类/项目管理/发布管理/`执行发布流程
  - 使用`功能分类/模板库/发布清单/`确保发布质量
  - 基于`索引文件/`进行资产清单检查

### 质量保证协作

#### 全流程质检
- **自动化质检 + 各角色Agent**：
  - 使用`业务分类/质量管理/`建立统一质量标准
