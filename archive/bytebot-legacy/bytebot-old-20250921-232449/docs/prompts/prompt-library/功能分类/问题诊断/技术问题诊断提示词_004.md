## 问题分类模板
- **前端问题**: 页面渲染、交互异常、兼容性问题
- **后端问题**: API异常、数据库问题、服务器错误
- **网络问题**: 连接超时、DNS解析、CDN问题
- **部署问题**: 环境配置、依赖缺失、权限问题
- **性能问题**: 响应慢、内存泄漏、CPU占用高
- **安全问题**: 漏洞发现、攻击检测、权限异常
