# 用户资料系统

## 项目概述

这是一个完整的用户资料收集和管理系统，为Trae IDE Agent提供智能化的用户画像功能。系统支持动态更新、标签化字段、版本管理等高级特性。

## 目录结构

```
用户资料系统/
├── README.md                    # 项目说明文档
├── 服务层/                      # 核心业务逻辑层
│   ├── user-profile.service.ts           # 核心用户资料服务
│   ├── user-profile-dynamic.service.ts   # 动态更新服务
│   └── user-profile-version.service.ts   # 版本管理服务
├── 集成层/                      # 系统集成层
│   └── user-profile.integration.ts       # Agent集成服务
├── 配置文件/                    # 配置和模式定义
│   └── user-profile.schema.json          # 数据模式定义
└── 文档/                        # 项目文档
    └── user-profile-guide.md             # 使用指南和最佳实践
```

## 快速开始

1. 查看 `文档/user-profile-guide.md` 获取详细使用指南
2. 从 `服务层/user-profile.service.ts` 开始了解核心功能
3. 参考 `集成层/user-profile.integration.ts` 了解集成方式
4. 使用 `配置文件/user-profile.schema.json` 了解数据结构

## 文件说明

### 服务层文件
- **user-profile.service.ts**: 核心服务，提供用户资料的CRUD操作
- **user-profile-dynamic.service.ts**: 动态更新服务，支持实时字段更新
- **user-profile-version.service.ts**: 版本管理服务，提供历史记录和回滚

### 集成层文件
- **user-profile.integration.ts**: Agent集成服务，连接用户资料系统与AI对话

### 配置文件
- **user-profile.schema.json**: JSON Schema定义，确保数据结构一致性

### 文档文件
- **user-profile-guide.md**: 完整的使用指南，包含API参考和最佳实践
