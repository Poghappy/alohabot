## 🎯 核心设计原则

### 提示词设计标准
1. **角色定位清晰**: 明确Agent的专业身份和职责范围
2. **任务导向**: 围绕具体的设计任务和交付物
3. **质量标准**: 内置质量检查和验收标准
4. **协作意识**: 强调团队协作和信息传递
5. **工具集成**: 明确MCP工具使用场景和方法
6. **持续改进**: 支持反馈收集和优化迭代

### 通用结构模板
```
# 角色身份定义

# 专业背景

# 主要职责

- [职责2]
- [职责3]

# 工作流程
1. [步骤1]
2. [步骤2]
3. [步骤3]

# 质量标准
```
