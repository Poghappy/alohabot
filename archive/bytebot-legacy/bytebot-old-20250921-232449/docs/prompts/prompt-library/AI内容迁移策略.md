# AI内容迁移策略

## 迁移概述

基于对项目的全面扫描，识别出以下AI相关内容需要迁移至提示词库：

### 1. AI相关文件分类

#### 1.1 智能体配置文件
- **文件类型**: YAML配置文件
- **主要文件**:
  - `trae-ide-agents/trae_agent_configs.yaml` - Trae IDE智能体配置
  - `helm/charts/*/values.yaml` - 容器化部署配置
- **迁移目标**: `技术分类/AI_ML/智能体配置/`

#### 1.2 提示词模板文件
- **文件类型**: Markdown文档
- **主要文件**:
  - `AI教学提示词模板.md` - AI教学相关提示词
  - `可复用提示词.md` - 通用可复用提示词
- **迁移目标**: `功能分类/方案生成/AI提示词模板/`

#### 1.3 智能体设计文档
- **文件类型**: Markdown文档
- **主要文件**:
  - `trae-ide-agents/visual_design_agent_squad_design.md` - 视觉设计智能体团队方案
  - `trae-ide-agents/initial_backlog_sprint_plan.md` - 初始Backlog与Sprint计划
  - `trae-ide-agents/智能体.md` - 智能体设计说明
  - `trae-ide-agents/品牌资源替换用户故事.md` - 品牌资源替换用户故事
- **迁移目标**: `业务分类/方案设计/智能体设计/`

#### 1.4 自动化工具配置
- **文件类型**: Shell脚本、JSON配置
- **主要文件**:
  - `setup_n8n_mcp.sh` - n8n MCP配置脚本
  - `n8n_mcp_example_config.json` - n8n MCP配置示例
- **迁移目标**: `技术分类/DevOps/自动化工具/`

#### 1.5 MCP服务器配置
- **文件类型**: TypeScript模块
- **主要文件**:
  - `packages/bytebotd/src/mcp/` - MCP模块实现
- **迁移目标**: `技术分类/后端技术/MCP集成/`

#### 2.2 迁移优先级

**高优先级**:
1. 智能体配置文件 - 直接影响系统功能
2. 提示词模板文件 - 核心复用资源
3. MCP服务器配置 - 技术集成关键

**中优先级**:
1. 智能体设计文档 - 方案参考资料
2. 自动化工具配置 - 运维支持工具

#### 2.3 文件处理规则

**保持原样规则**:
- 所有文件内容保持不变
- 保留原始文件路径信息
- 维护文件间的引用关系

**元数据添加**:
- 为每个文件添加来源路径
- 记录迁移时间和版本
- 标注文件用途和依赖关系

### 3. 索引和元数据规范

#### 3.1 文件索引格式

```yaml
file_id: "ai_config_001"
original_path: "trae-ide-agents/trae_agent_configs.yaml"
migrated_path: "技术分类/AI_ML/智能体配置/trae_ide_configs/"
file_type: "配置文件"
category: "智能体配置"
tags: ["trae-ide", "智能体", "配置", "YAML"]
description: "Trae IDE智能体团队配置文件"
dependencies: []
related_files: []
created_at: "2024-01-XX"
migrated_at: "2024-01-XX"
version: "1.0"
```

#### 3.2 元数据字段说明

- **file_id**: 唯一标识符
- **original_path**: 原始文件路径
- **migrated_path**: 迁移后路径
- **file_type**: 文件类型（配置文件、文档、脚本等）
- **category**: 业务分类
- **tags**: 关键词标签
- **description**: 文件描述
- **dependencies**: 依赖文件列表
- **related_files**: 相关文件列表
- **created_at**: 原始创建时间
- **migrated_at**: 迁移时间
- **version**: 版本号
