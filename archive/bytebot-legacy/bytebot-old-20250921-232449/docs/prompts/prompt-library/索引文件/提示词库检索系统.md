## 使用指南

### 快速查找
1. **按角色查找**: 根据团队角色标签快速定位相关资源
2. **按项目阶段查找**: 根据项目进度查找对应阶段的文档
3. **按技术栈查找**: 根据使用的技术栈查找相关配置
4. **按问题类型查找**: 根据遇到的问题类型查找解决方案

### 搜索技巧
- **组合搜索**: 使用多个关键词组合搜索，如"智能体 + 配置"
- **排除搜索**: 使用"-"排除不需要的结果，如"配置 -测试"
- **精确搜索**: 使用引号进行精确匹配，如"trae-ide-agents"
- **通配符搜索**: 使用"*"进行模糊匹配，如"config*"

### 文件关联
每个文件都包含以下关联信息：
- **依赖文件**: 该文件依赖的其他文件
- **被依赖文件**: 依赖该文件的其他文件
- **相关文件**: 功能相关的其他文件
- **替代文件**: 可替代使用的文件
