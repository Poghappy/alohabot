## 🤝 Agent 协作机制

### 任务分配
- **主要 Agent**: 负责当前阶段的核心任务
- **辅助 Agent**: 提供支持和质量保证
- **协作 Agent**: 处理跨模块的集成任务

### 信息传递
- **上下文共享**: 通过 Cursor Rules 共享项目信息
- **进度同步**: 定期更新任务状态和完成情况
- **问题反馈**: 及时报告和解决技术问题

### 质量检查
- **阶段验收**: 每个阶段完成后进行质量检查
- **持续集成**: 代码提交时自动运行测试
- **性能监控**: 实时监控应用性能和稳定性

### 持续改进
- **反馈收集**: 收集使用反馈和问题报告
- **配置优化**: 根据反馈优化 Agent 配置
- **知识积累**: 将经验转化为最佳实践
